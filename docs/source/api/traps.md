# courlan.traps

Optional monitoring for crawl traps: calendar widgets, filter combinations and
soft-404 endpoints that expose infinitely many URLs for a finite set of
responses. Detection only produces evidence-backed suggestions; nothing is
limited until the caller enables a rule, and disabling a rule restores every
candidate URL.

For a walkthrough see the [crawling guide](../usage/crawling.md).
